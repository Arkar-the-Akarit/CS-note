
statement ဆိုတာ ကွန်ပြူတာကို ဘာလုပ်ပါ, ဘာလုပ်ပါဆိုပြီး ခိုင်းလိုက်တာ

1. Normal Statement - print ထုတ်လိုက်ပါ။ data obj တစ်ခုဖန်တီးပါ။ အဲ့လို ရိုးရိုးလေး

2. conditional statement - သူကျက ရွေးချယ်စရာ အခြေအနေပေါမူတည်ပြီး လုပ်သင့်တာလုပ်ဆိုတာမျိုး

###### Conditional Statement

<mark style="background: #FFF3A3A6;">if , elif , else</mark>

သူတို့က boolean (true, false) ပေါ်မူတည်ပြီး အလုပ်လုပ်တယ်။ အခြား data type ဝင်နေရင်လည်း boolean အဖြစ်ဆုံးဖြတ်ပြီး ဆက်အလုပ်လုပ်တယ်။ (0 and empty data obj ဆို false, other int and valued data is true like that)

if, elif, else <span style="color:rgb(0, 176, 240)">တွဲသုံး</span>ရင် condition တစ်ခုမှန်သွားတာနဲ့ အောက်ကကျန်တဲ့condition တွေကို ဆက်မစစ်ဘဲ မှန်တဲ့ တစ်ခုကိုဘဲ ထုတ်ပေးမှာ။ 

ဒီအောက်က program ဆိုရင် elif တွေနဲ့ တွဲထားတာ if ကစ else အထိမှ one conditional statement အဖြစ်သတ်မှတ်တယ်။ တွဲရေးထားလို့
```
if condition1 : print("a")
 else: print("b")

if condition1: 
	print("a")    # if this is true, two conditions under are passed
elif condition2:
	print("b")
else:
	print("c")


```

###### if

တစ်ကြောင်းထဲဆိုရင် `if condition: statement` ဆိုပြီးရေးလို့ရ

တစ်ကြောင်းအထက်ဆို if condition: အောက်မှာ space လေးချက် (tab) ခြားပြီးရေးလို့ရ
```
if condition1:
	statement1
	statement2

```

input string ကို empty ဖြစ်လား မဖြစ်လား စစ်တာလည်းရ like if input: ... else: ....

###### else

else က for, while, တို့နဲ့ တွဲသုံးတယ်။ သူနဲ့ချိတ်ဆက်ထားပြီဆိုရင် သူ့အပေါ်က ကောင်က false ဖြစ်တယ်ဆိုရင် else အောက်က statement ကို runပေးမှာ

```
if conditionFalse:
	statementIsPassed
else:
	thisStatementWillWork

  ----------------------

if conditionTrue:
	statementWillWork
else:
	thisIsPassedNow

```

###### elif

else နဲ့ရိုးရိုးဆက်ရင် နောက် condition တစ်ခုထည့်လို့မရဘူး။ ဒီတော့ ထည့်ချင်တယ်ဆိုရင် else + if = elif condition: ဆိုပြီး သုံးပြီး ထပ်ပြီး လိုအပ်တဲ့ condition တွေ ထည့်လို့ရတယ်။
