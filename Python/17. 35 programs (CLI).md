CLI - command line interface

###### 1. Basic input & output

input() -> user ရိုက်ထည့်မယ်စာတွေကို လက်ခံဖို့။ always <mark style="background: #FFF3A3A6;">return as string 
</mark>
print() -> စာတွေကို print ထုတ်ဖို့
	သူ့ထဲမှာ အခြားသော value တွေ, ပြချင်တာတွေကို coma လေးြခားပြီး ပြလို့ရ 
	`print("hello",1,2.0) #hello 1 2.0`

###### Format ချနည်း

print နဲ့ ရိုးရိုး <span style="color:rgb(0, 255, 255)">label + coma</span> နဲ့ ရေးလို့ရသလို <span style="color:rgb(255, 105, 180)">f</span> နဲ့ format ချပြီး " " string ထဲမှာ ထည့်လို့ရတယ်။

<mark style="background: #BBFABBA6;">syntax</mark> - ` f"{label} some text {label2}"  `
		  `f"{label : .2f}" `

```
l1 = input()
l2 = input()

ans = f"{l1} text {l2}" , print(ans)
#or  
print(f"{l1} text {l2}")

to get to specific deciaml point on float

f"{l1:.2f}
```
