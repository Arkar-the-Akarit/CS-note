
###### 1. Operand 

Operation တစ်ခုလုပ်ဆောင်တယ်ဆိုရင် operation ထဲမှာ ပါဝင်နေတဲ့သူတွေကို operand လို့ခေါ်ပြီး operation ကိုလုပ်ဆောင်ပေးတဲ့သူကို operator လို့ခေါ်တယ်။

- left operand
- right operand

```
     1  +  2
    /   |   \
left    |    right
	operator
(additional operation)
```

အပေါ်က အပေါင်း operation မှာ ပေါင်းဖို့လုပ်ဆောင်ပေးတာသည် operator (+ sign here) , အဲ့ operator ရဲ့ ဘယ်ဘက်ကကောင်သည် left operand, ညာဘက်ကောင်သည် right operand. operand တွေက အပေါင်းခံရ

- Unary Operator
	operand (၁) ခုတည်းနဲ့ အလုပ်လုပ်တဲ့ operator
	operand သည် သူ့ညာဘက်မှာရှိတယ်။
	
	<mark style="background: #ABF7F7A6;">(၄)မျိုး</mark> ဘဲရှိ ။ သူ့လေးမျိုးကလွဲပြီး ကျန်တဲ့ မသိတဲ့ operator တွေတွေ့ရင် binary operators အုပ်စုထဲကမှန်းသိရမယ်။
	
	1. unary Plus --> +1 
		အပေါင်းကိန်းဖြစ်ကြောင်းပြဖို့သုံးတာဖြစ်တယ်။ ထည့်မရေးဘဲ ရိုးရိုး 1 လို့ရေးလည်း ရတယ်။ unary plus သုံးတာကို သိဖို့။
	
	2. unary minus --> -1
		အနှုတ်ကိန်းဖြစ်ကြောင်း သိစေဖို့ ထည့်သုံးရတာဖြစ်တယ်။ အနှုတ်ကိန်း , negative int တွေကို ဖော်ပြဖို့သုံး
	
	3. logical NOT --> not
		<mark style="background: #ABF7F7A6;">boolean value တွေကို ဆန့်ကျင်ဘက်ပြောင်း</mark>။ true ဆို false ပြောင်း, false ဆုိ true ပြောင်းပေးတယ်။
	
	4. bitwise NOT --> ~
		ဒီကောင်ကျ <mark style="background: #FFF3A3A6;">binary data</mark> တွေကို 0 ဆုိ 1 ပြောင်း , 1 ဆို 0 ပြောင်း
