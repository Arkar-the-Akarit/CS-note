-> high-level, interpreted language
	from left - right, top - bottom 
	 parenthesis ပါရင် parenthesis ထဲက ဟာကို ဦးစားပေး 
```
 e.g. work1 (work2); work3 (work4 (work5)); work6. ..                    
Executing order - work2, work1, work5 work4 work3, work6
```

-> လိုင်းတစ်ကြောင်းကို statement တစ်ခုအဖြစ်ယူဆ
-> (;) ကိုလည်း statement terminator လို့ သတ်မှတ်
-> fully supported OOP, partly support FP
