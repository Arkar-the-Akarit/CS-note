
Precedence <mark style="background: #FFF3A3A6;">အဆင့် (၉)</mark> မှာရှိ။ ဒီ comparison, identity, membership operators တွေက boolean value တွေ ပြန်ပေးတယ်။

###### Comparison Operator  (Compare Value)

equal to                    -->   =\=
not equal to                -->   !\=
greater than                -->   >
less than                   -->   <
greater than or equal to    -->   >\=
less than or equal to       -->   <\=

နှိုင်းယှဥ်လိုက်တာမှန်ရင် true, မှားရင် false return ပြန်

```
x = ['apple', 'banana', 'orange']

x > ['apple', 'banana']  # return True
x > ['bpple', 'banana']  # return false

ဘာလို့လဲ ဆိုတော့ python က နှိုင်းယှဥ်တဲ့အခါမှာ အထဲမှာရှိနေတဲ့ list item အရေအတွက်နဲ့ နှိုင်းယှဥ်တာမဟုတ်ဘဲ ပါဝင်တဲ့ items တွေရဲ့ unicode decimal value တွေနဲ့ ယှဥ်တာ where a = 64 and b = 65 ဒါကြောင့် false


```


###### Identity Operators  (<span style="color:rgb(0, 176, 240)">Compare Memory Locations</span>)
 
identical objects         -->    is 
not identical objects     -->    is not

သူသည်  <mark style="background: #ABF7F7A6;">memory address တူမတူ စစ်</mark>ပေးတာဖြစ်တယ်။

note -> memory address ကို စစ်ချင်ရင် <mark style="background: #FFF3A3A6;">id()</mark> ကိုသုံး


###### Membership Operators (Test for membership in sequence)

Present in the sequence      -->  in
Not present in the sequence  -->  not in

အဖွဲ့ဝင် ဟုတ်မဟုတ်စစ်တာ။ လိုချင်တဲ့ data ရှိမရှိရှာတာ။

```
x = ['apple', 'banana', 'orange']
'apple'  in x   # return True
'mango'  in x  # return False

```
