
###### 1. chr(x)

convert an integer to a character
```
chr(0x1f34e)
>>   #apple emoji as output

```

###### 2. ord(x)

ordinal number - လူ/ပစ္စည်းတစ်ခုရဲ့ နေရာ, rank ကိုဖော်ပြဖို့သုံးတဲ့ နံပါတ်တွေ

ဒီ function က a single character ကို unicode table ထဲက တူညီတဲ့ integer value အဖြစ်ပြောင်းပေးတယ်

###### 3. bin(x)

integer -> a <mark style="background: #FFF3A3A6;">binary string</mark>

###### 4. oct(x)

integer -> an <mark style="background: #FFF3A3A6;">octal string</mark>

###### 5. hex(x)

integer -> a <mark style="background: #FFB86CA6;">hexadecimal string</mark>

###### 6. repr(x)

သူကလည်း str() လိုဘဲ string ပြန်ပေးပေမယ့် သူပြန်ပေးတာက
representation string - ကိုယ်စားပြုတဲ့ string စာတန်ဖိုး

###### 7. eval(str)

<mark style="background: #FFF3A3A6;">string တန်ဖိုးတစ်ခု</mark> ကို evaluate (တွက်ချက်ပြီး) <mark style="background: #FFF3A3A6;">object return</mark>ပြန်

သူ့ထဲကို ထည့်လိုက်တဲ့ စာတန်ဖိုးကို program တစ်ခုအဖြစ်သတ်မှတ်ပြီး ဘာသာပြန် / object return ပြန် 

e.g.

`eval("False")`  output -> False (not string, Boolean Value)

`eval("1")` output -> 1 (integer value)
`eval("1 + 2")` output -> 3 (integer value)

`eval("\['apple','banana'])` output -> \['apple','banana'] (list value)
