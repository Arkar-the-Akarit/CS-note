###### three phases of a program

ယေဘုယျအားဖြင့် သုံးဆင့်

1. Input - လိုအပ်တဲ့ data တွေကို ထည့်သွင်းပေးတာ
2. Processing - computer က ရေးထားတဲ့ code တွေကို လုပ်ဆောင်ပေး
3. output - ရလဒ်ပြန်ထုတ်ပေးတာ
-----------------------------------------------------
