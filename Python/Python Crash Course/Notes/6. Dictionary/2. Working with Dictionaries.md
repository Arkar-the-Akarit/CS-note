###### Using get() to Access Values

key ကို index လိုသုံးပြီးထုတ်တာက ထည့်လိုက်တဲ့ key မရှိဘူးဆိုရင် error တက်နိုင်တယ်။ ဒီလိုမဖြစ်အောင် <mark style="background: #FFF3A3A6;">get()</mark> method ကိုသုံးလို့ရတယ်။

syntax - <mark style="background: #BBFABBA6;">get(key, value to return if key dont exist(option))</mark>

အကယ်လို့ key မရှိရင် ပြရမယ့် optional value ကိုမထည့်ထားဆိုရင် python သည် <mark style="background: #ABF7F7A6;">None</mark> ဆိုပြီး none type ကို return ပြန်မယ်။

None - a special value to indicate the absence of a value

```
e.g. 

user = ['name':'g', 'age' : 3]

value = user.get('height', 'no value assigned for hegiht')

print(value) # will print optional message 

```
