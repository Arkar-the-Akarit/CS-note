
###### looping through all key-value pairs

for loop နဲ့ <mark style="background: #FFF3A3A6;">.items()</mark> method ကို သုံးပြီး dict ထဲက key နဲ့ value ကိုအတွဲလိုက်ဆီထုတ်လို့ရတယ်။

syntax : 
```
for key,value in dict.items():
	print(key)
	print(value)

```

for နောက်က လိုက်မယ့် label နှစ်ခုသည် ပေးချင်တဲ့နာမည်ပေးလို့၇တယ်။ <span style="color:rgb(0, 176, 240)">ပထမတစ်ခု</span>သည် <span style="color:rgb(0, 176, 240)">key</span>ကိုညွှန်းပြီး <span style="color:rgb(255, 155, 0)">ဒုတိယတစ်ခု</span>သည် <span style="color:rgb(255, 155, 0)">value</span> ကိုညွှန်းတယ်။

.items() သည် dictionary ရဲ့ method ဖြစ်ပြီး view object (dictionary items object)တွေကို return ပြန်လာတာဖြစ်တယ်။ [[26. Iteration#iterable objects|iterable]] တစ်ခုအနေနဲ့အလုပ်လုပ်ပြီး index သွားတပ်ပြီး ထုတ်ကြည့်လုိ့မရ

```
e.g.

v = dict.items() 

v[o] # အမှား မရပါ အဲ့လို

print(v)ဆိုရင်တော့ tupleလိုပုံမျိုးထွက်တတ်သလို interpreter ပေါ်မူတည်ပြီး object locationကိုပြတာလည်းဖြစ်နိုင်တယ်။

```

loop ပတ်တာအပြင် .items နဲ့ dict ကို listထဲထည့်လိုက်လို့ရတယ်။ key,value အတွဲတိုင်းက tuple တစ်ခုစီဖြစ် list ထဲဝင်သွားမယ်။

```
dict = {'a' : 1, 'b':2,'b':3}


list = [dict.items()]

print(list) # [('a',1),('b',2),('c',3)]

list[0]  # ('a',1)
list[0][1] # ('a')
list[0][2] # (1)




```
