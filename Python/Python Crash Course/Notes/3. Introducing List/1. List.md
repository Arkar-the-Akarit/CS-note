
list = a collection of items in particular order

- good to store collections of items that can change throughout the program

naming conventions - should be <mark style="background: #FFF3A3A6;">plural</mark>

- <mark style="background: #ABF7F7A6;">Squar Bracket ([])</mark> indicates list

`e.g. bicycles = ['trek', 'cannondale', 'redline', 'specialized']`

###### Accessing elements in a list

by <mark style="background: #FFF3A3A6;">using the index</mark>

`e.g. bicycles[0] #trek`

string တုန်းက သိခဲ့တဲ့ strip(), title() စတဲ့ method တွေကိုလည်း individual list elements အပေါ်မှာ သုံးလို့ရတယ်။

###### index positions start at 0, not 1

index starts at position 0, not position 1.
because it is implemented at lower level.


special syntax - list\[-1] - always return the last item

###### Using Individual values from a list

အခြား variables တွေလိုဘဲ individual item တစ်ခုဆီကို သုံးလို့ရ
