
###### Modifying Elements in a List

```
plants = ['rose','padauk','grass']

plants[0] = 'flaming' # ['flaming','padauk','grass']




```

##### Adding elements to a List

existing list ဘာညာထဲကို data အသစ်ထည့်နည်း အများကြီးရှိ

###### Appending Elements to the End of a list

အလွယ်ဆုံးကတော့ <mark style="background: #FFB86CA6;">append('itemName') </mark>
သူက list ရဲ့ အနောက်ဆုံးမှာ ထည့်လိုက်တဲ့ items တွေကို ဖြည့်ဖြည့်ပေးမယ်။

`plants.append("boom")`

###### Inserting Elements into a List

append သည် နောက်ဆုံးမှာမှ ထပ်ထည့်ပေးတာဖြစ်တဲ့အတွက် ထည့်ချင်တဲ့နေရာမှာ ထည့်ဖို့ဆိုရင် 

<mark style="background: #FFF3A3A6;">insert(indexPosition, itemName)</mark>

သူသည် ထည့်လိုက်တဲ့ index နေရာမှာရှိတဲ့ကောင်က ပျောက်သွားမှာ မဟုတ်ဘူး။ ဘေးကို ဆက်တိုးသွားမှာ။ like this

```
tests = ['a','b','c','d']

tests.insert(1,'z')
# ['a','z','b','c','d']



```


အကယ်လို့ ကိုယ်ထည့်လိုက်တဲ့ index position က list ရဲ့ length ထက်ကြီးနေတယ်ဆိုရင် item အသစ်သည် listရဲ့ အဆုံးနေရာကိုဘဲရောက်တယ်။ e.g. num = \[1,2,3] ကို num.insert(100,4) ဆိုရင်တောင် num = \[1,2,3,4] ဖြစ်သွားမယ်။

##### Removing Elements from a list.

###### Removing an item using del statement

ကိုယ်ဖျက်ချင်တဲ့ element ရဲ့ index position ကိုသိတယ်ဆိုရင် <mark style="background: #ABF7F7A6;">'del'</mark> statement ကို သုံးပြီး ဖျက်လို့၊ same for the variable

```
del list[index]
del variable

```

Removing an item using pop() method

pop() method သည် ကိုယ် apply လုပ်လိုက်တဲ့ list ထဲက နောက်ဆုံးတစ်လုံးကို ယူပလိုက်တာမျိုး။ ယူလိုက်တာသည် list ထဲမှာ မကျန်တော့ဘူး။ ပျက်သွားပြီ။ ဒါပေမယ့် တစ်ခါတည်း label တစ်ခုမှာ assign ထည့်ပေးလိုက်လို့ပြီး ယူ/ဖျက်လိုက်တဲ့ item ကို အသုံးလိုရင် သုံးဖုိ့ချန်ထားလုိ့ရ

```
motorcycles = ['honda','suzuki','yamaha']

popped_motorcycles = motorcycles.pop()

  

print(motorcycles)  # ['honda', 'suzuki']

print(popped_motorcycles) # 'suzuki'

```

အကယ်လို့ <mark style="background: #FFF3A3A6;">index ပါထည့်</mark>ပေးလိုက်မယ်ဆိုရင် ကိုယ်<mark style="background: #FFF3A3A6;">လိုချင်တဲ့နေရာက element ကို pop လုပ်လို့</mark>ရ။

```
num = ['zero','one','two','three']

popped_one = num.pop(1)

print(popped_one)  # 'one'

```

###### Removing an item by Value

အကယ်လို့ index positionကို သိမနေဘူး, item value ကိုတော့ သိတယ်ဆိုရင် <mark style="background: #BBFABBA6;">remove()</mark> method ကိုသုံးပြီး remove လုပ်လို့ရ

```
fruits = ['banana', 'apple', 'strawberry' ,'pineapple']

fruits.remove('apple')

print(fruits) # ['banana', 'strawberry', 'pineapple']
```

list ထဲကနဲ့ တူညီတဲ့ value ကို label မှာ assign လုပ်ပြီး <mark style="background: #BBFABBA6;">remove(label)</mark> နဲ့ ထုတ်ပစ်လည်းရ

```
too_sour = 'pineapple'

fruists.remove(too_sour) # pineapple is removed from the list

```

remove() method သည် value ကိုသုံးတာဖြစ်တဲ့အတွက် ကိုယ် specify လုပ်လိုက်တဲ့ value နဲ့ ပထမဆုံးတူတာကို remove လုပ်ပစ်မှာဖြစ်တယ်။ တူညီတဲ့ value တွေ နှစ်ခုနဲ့ အထက်ပါနေရင်တော့ ဒုတိယတစ်ခုကစပြီး ကျန်တဲ့ကောင်တွေပါပျက်ဖို့က loop ပတ်ရမယ်။

###### To Note

မမေ့ရမှာကို item တွေကို remove, del, pop လုပ်တဲ့အခါမှာ item တစ်ခုထွက်သွားတိုင်း total index သည် တစ်ခုလျော့သွားတာကို သတိပြုရမယ်။ ဆိုရရင် loop ပတ်ပြီး remove ချလိုက်မယ်။ စစချင်း index 7 ခန်းရှိမယ်။ အဲ့တာကို loop နဲ့ remove လုပ်လာရင် index 0,1,2,3 အထိတော့ အဆင်ပြေမယ်။ index လေးခုအပြီးမှာ i သည် 4 ဖြစ်လာမယ်။ ဒါပေမယ့် remove လုပ်တိုင်း index က လျော့လျော့သွားတဲ့အတွက် total index သည် 3 ဖြစ်ပြီး index out of range error တက်နိုင်
