list တွေက တစ်ခါတလေမှာ ကိုယ့်ထည့်လိုက်တဲ့ အစဥ်တိုင်း သုံးတာပိုကောင်းသလို, တစ်ခါတလေမှာတော့ လိုသလို စီသုံးတာပိုကောင်းတယ်။ python မှာက အဲ့လို စီဖို့အတွက် နည်းတွေအများကြီးရှိ

###### Sorting a list Permanently with Sort() method

လွယ်လွယ်ကူကူ sort လုပ်နိုင်ဖို့ <mark style="background: #ABF7F7A6;">sort()</mark> method ကိုသုံး

```
cars = ['bmw', 'audi', 'toyota', 'subaru']
cars.sort()  # 'audi','bmw','subaru', 'toyota'


```

သူသည် sort လုပ်ဖို့အတွက် sort method ကို list အပေါ်မှာ act လုပ်ခိုင်းတာ။ ပြီးရင် အဲ့ list ကို ထုတ်ကြည့်ရင် sorted ဖြစ်သွားတာကိုတွေ့ရမယ်။ ဒါပေမယ့် `newList = list.sort()` 
ဆိုပြီး <mark style="background: #FF5582A6;">လုပ်လို့မရ</mark> <mark style="background: #FFB8EBA6;">None typeဘဲ</mark> ပြန်ရမယ်

to sort reverse-alphabetical - <mark style="background: #ABF7F7A6;">sort(revese=Trure)</mark>

sort() method ကိုသုံးလိုက်ပြီဆိုရင် အဲ့ list သည် <mark style="background: #BBFABBA6;">လုံးဝအစီစဥ်ပြောင်း</mark>သွားပြီ။

###### Sorting a list Temporarily with sorted() function

original order အစီစဥ်တိုင်းလေးလည်းကျန်ချင်တယ်။ sort လုပ်ပြီးသားကိုလည်း ပြချင်တယ်ဆိုရင် listကို <mark style="background: #ABF7F7A6;">sorted()</mark> function ထဲကို arguments အနေနဲ့ passed လုပ်လိုက်လို့ရတယ်။ 

```
print("Here is the original list:")  
print(cars)  

print("\nHere is the sorted list:")  
print(sorted(cars))  

print("\nHere is the original list again:")  
print(cars)

```


###### To Note

list တစ်ခုကို alphabetically sort လုပ်တဲ့အခါမှာ list ထဲက values တွေက lowercase ဖြစ်မနေရင် နည်းနည်းရှူပ်တယ်။ ဒါပေမယ့် will be fine.

###### Printing a list in Reverse Order

list တစ်ခုကို အနောက်ဆုံးကနေ အရှေဆုံးကို ထုတ်ချင်တာမျိုး၊ list item တွေကို <mark style="background: #FFB8EBA6;">alphabetically ဘာညာ မစီဘဲ</mark>, <mark style="background: #ADCCFFA6;">သူ့ရှိနေတဲ့အစဥ်အတိုင်းကို အနောက်ကကောင်တွေကို အရှေ့ပို့ပစ်တာမျိုးဆို </mark> <mark style="background: #ABF7F7A6;"> reverse() </mark> method ကိုသုံးလို့ရတယ်။
သူသည်လည်း sort() လိုဘဲ order ကို permanently ပြောင်းပစ်တာဖြစ်တယ်။

```
cars = ['bmw','audi','toyota','subaru']
cars.reverse()

print(cars)  #['subaru', 'toyota', 'audi', 'bmw']


```

###### Finding the length of a List

<mark style="background: #ABF7F7A6;">len()</mark> function ကိုသုံးပြီး list တစ်ခုထဲမှာ item ဘယ်နှစ်ခုရှိတယ် or list ရဲ့ length ဘယ်လောက်ရှိလဲ ကြည့်လို့ရတယ်။

```
cars = ['bmw', 'audi', 'totyta', 'suzuki']
len(cars)  # 4
```
