###### Checking that a list is not Empty

empty data type အများစုသည် 0/false ဖြစ်တဲ့အတွက်

<mark style="background: #CACFD9A6;">if list:</mark> ဆိုရင် list ထဲမှာ items ရှိမှ အလုပ်လုပ်မှာဖြစ်ပါတယ်။

```
requested_toppings = []  

if requested_toppings:  
	for requested_topping in requested_toppings:  
		print(f"Adding {requested_topping}.")  
	print("\nFinished making your pizza!")  
else:  
	print("Are you sure you want a plain pizza?")

```

###### Using Multiple Lists

multiple lists တွေသုံးပြီး အလုပ်လုပ်လို့ရတယ်။ 
ဥပမာ available items list ကို requested item list နဲ့ တိုက်စစ်ပြီး ပစ္စည်းရှိမရှိပြောတာမျိုး

```
available_items = ['a','b','c','d','e']

requested_items = ['c','b','g']

for item in requested_items:
	if item in available_items:
		print(f"{item} is available")
	else:
		pritn(f"{item} is currenlty out of stock")

```
