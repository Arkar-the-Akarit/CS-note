
###### Checking for Equality

double equal sign (=\=)

```
car = 'bmw'  # value assign
car == 'bmw' # true, equality check

```

###### Ignoring Case when checking for Equality

testing for equality in python - Case Sensitive

###### Checking for inequality

တန်ဖိုးနှစ်ခု မတူဘူးလား ဆိုတာကို စစ်ချင်ရင်  <mark style="background: #FFF3A3A6;">! =</mark>

```
num = 'a'

num != 'b' # true
num != 'a' # false

```

###### Numerical Comparisons

numbers တွေကိုလည်း equality, inequality operators တွေကိုသုံးပြီးလဲ စစ်လို့ရတယ်။

အဲ့တာအပြင် greater than (>) , less than (<) , greater than equal to (>=) , less than or equal to (<=) စတာတွေသုံးလုိ့လည်းရ

##### Checking Multiple Conditions

###### Using 'and' to check Multiple Conditions

conditions နှစ်ခု/အထက် <mark style="background: #FFF3A3A6;">အကုန် true</mark> ဖြစ််မှရမယ်ဆို <mark style="background: #BBFABBA6;">and</mark> ကိုသုံးတယ်။

```
if a > 10 and b < 3:

```

###### Using 'or' to check Multiple Conditions

ထည့်ထားတဲ့ conditions နှစ်ခု/အထက်ထဲက <span style="color:rgb(0, 176, 240)">တစ်ခုမှန်တာနဲ့ ရ</span>ပြီဆို <mark style="background: #BBFABBA6;">or</mark> 

```
if a < 2 or b > 5:

```

###### checking whether is  in / not in a List

membership operator ဖြစ်တဲ့ <mark style="background: #ABF7F7A6;">in</mark> / <mark style="background: #ABF7F7A6;">not in</mark> ကိုသုံးပြီး value တစ်ခုဟာ list ထဲမှာ ရှိမရှိ စစ်နိုင်

```
fruits = ['apple','orange','banana']

'apple' in fruits   # true
'apple' not in fruits # false

'monke' not in fruits # true
'monke' in fruits # false


```

###### Boolean Expressions

boolean value is <mark style="background: #ABF7F7A6;">True</mark> or <mark style="background: #ADCCFFA6;">False</mark>, just like the value of a conditional expression.

အချို့ conditions တွေကို စောင့်ကြည့်ဖုိ့ boolean values တွေကိုသုံးတယ်။
