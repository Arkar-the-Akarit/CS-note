
conditional tests တွေကို နားလည်သွားပြီဆိုရင် if statements တွေကိုသုံးလုိ့ရ။

###### Simple If Statements

```
if conditional_test:
	do something

```

###### if-else Statements

```
if condition1:
	statement
else:
	statement

```

###### if-elif-else

```
if condition1:
	statement
elif condtition2:
	statement
else:
	statement

# multiple elif

if con1:
	statement
elif con2:
	stmt2
elif con3:
	stmt3
elif con4:
	stmt4
else:
	stmt5

```

###### Omitting the else block

else block သည် လိုမှ ထည့်သုံးလို့ရတယ်။ if-elif ဘဲသုံးပြီး မသုံးဘဲထားခဲ့လည်းရတယ်။
