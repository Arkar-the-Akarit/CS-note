
list - ideal for storing sets of numbers

###### Using range() function

<mark style="background: #FFB86CA6;">range()</mark> ကိုသုံးပြီး numbers တွေထုတ်လို့ရ

<mark style="background: #ABF7F7A6;">range(start(o),stop,step(o))</mark>
start - inclusive (include the num define as start)
stop - exclusive (the num defined as stop wont be included)

###### Using range() to make a list of numbers

range() ကို list ထဲ တစ်ခါတည်းထည့်ချပြီး နံပါတ်တွေထုတ်တာ

`num = list[range(1,5)]`

```
# store the squared value of first ten integers.

squares = []

for i in range(11):
	squares.append(i**2)

print(squares)

```

###### Simple Statistics with a List of Numbers

minimum, maximum, total sum of list ကို ရှာဖို့ <mark style="background: #ABF7F7A6;">min()</mark>, <mark style="background: #ADCCFFA6;">max()</mark>, <mark style="background: #D2B3FFA6;">sum()</mark> function တွေရှိ

```
digits = [1,2,3,4,5,6,7,8,9,0]

min(digits)  # 0

max(digits)  # 9

sum (digits)  # 45

```


###### List Comprehensions

range funt + for loop ကိုသုံးပြီးမှ append နဲ့ squared value တွေကို list ထဲထည့်တာ အပေါ်က program မှာ ပြထားတယ်။

python မှာက <mark style="background: #FFF3A3A6;">list comprehension</mark> ဆိုတာမျိုးရှိပြီးတော့ သူက အပေါ်ကလို program မျိုး (code သုံးလေးကြောင်း) ရေးစရာမလိုဘဲ တစ်ကြောင်းထဲ ရေးလို့ရတယ်။ ပြောရမယ်ဆိုရင် list comprehension ဆိုတာ f<mark style="background: #BBFABBA6;">or loop နဲ့ element values တွေ ဖန်တီးတာကို code တစ်ကြောင်းတည်းအဖြစ် ပေါင်း</mark>ထားတာဘဲ

step:
1. Open a set of square brackets for list
2. Define the <mark style="background: #FFF3A3A6;">expression</mark> (e.g. value ** 2)for the values we want to store in the list
3. Write a for loop to generate the numbers we want to feed into the expression
4. Close the square bracket

syntax : <mark style="background: #BBFABBA6;">list = [expression for tempExpressionValue in range()]</mark> 

<mark style="background: #FF5582A6;">သတိပြုရန်</mark>
- list comprehension နဲ့ သုံးရင် expression နေရာမှာ feed လုပ်ချင်တဲ့ temp variable က for tempVariable နဲ့ name တူရမယ်။ like `[value **2 for i in  ..` ဆိုမှားတယ်။ value ကို ယူသုံးထားရင် define လုပ်ပေးရမယ်။ its either `[i**2 for i in..]` or `[value**2 for value in`
- နောက်တစ်ခုက list comprehension နဲ့သုံးရင် for loop အဆုံးမှာ<mark style="background: #BBFABBA6;"> colon (:)</mark> မလို

```
# creating a list with squared values of first ten integer

squared_num = [value ** 2 for value in range(1,11)]

```
