###### Looping through a Slice

list တစ်ခုကို အပြည့်မသုံးဘဲ slice လုပ်ပြီးမှ loop ထုတ်လည်းရ

```
chars = ['a','b','c','d','e']

for char in chars[:3]:  # ['a',-,'c']
	print(char)  # a , b, c

```
