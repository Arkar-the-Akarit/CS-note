<mark style="background: #ADCCFFA6;">list</mark> သည် <mark style="background: #ADCCFFA6;">mutable (changable)</mark> ဖြစ်ပြီးတော့ 
အကယ်လို့ <mark style="background: #ABF7F7A6;">ပြုပြင်ပြောင်းလဲလို့မရတဲ့ (immutable)</mark> ဖြစ်တဲ့ collection မျိုးလိုချင်တာဆို <mark style="background: #ABF7F7A6;">tuple</mark> ရှိ

###### Defining a Tuple

<mark style="background: #FFF3A3A6;">tuple = (item1,item2)</mark>

note - tuple ဆိုပြီး အဓိကဖြစ်စေတာသည် <mark style="background: #FFF3A3A6;">value တွေကို coma ခြားပြီးရေးတာက</mark>ဖြစ်တယ်။ လက်သည်းကွင်းက ပိုပြီးဖတ်ရလွယ်အောင်ရယ် သပ်သပ်ရပ်ရပ်ရှိအောင်ထည့်ထားတာ။ 
ဒါကြောင့်မလုိ့ <mark style="background: #ABF7F7A6;">element တစ်ခုထဲရှိတဲ့ tuple</mark> ဖန်တီးချင်ရင်တောင် <mark style="background: #D2B3FFA6;">သူ့နောက်မှာ coma ထည့်ပေးရ</mark>
`tuple = (item1,)`

list လိုဘဲ index / slicing ဘာညာ စမာလကာ
တစ်ခုဘဲ အထဲက value တွေကို <mark style="background: #ABF7F7A6;">ပြောင်းလို့မရ</mark> 

```
tuple = (200,100,150)

tuple[0] = 50 # will get into error


```

###### Looping through all values in a Tuple

list လိုဘဲ for loop နဲ့ ထုတ်လို့ရ

```
nums = (1,2,3,4,5)

for num in nums:
	print(num)

```

###### Writing over a Tuple

tuple အထဲက value တွေကို ပြင်လို့ထပ်ထည့်လို့မရပေမယ့် tuple type assign လုပ်ထားတဲ့ labelမှာ tuple အသစ်ကြီးတစ်ခု assign လုပ်ပစ်ပြီး ပြင်လိုက်တဲ့ပုံတော့ လုပ်လို့ရ

```
num = (1,2,3)

num[0] = 4 # error, မရ,

num =  (4,2,3) ရ

```
