
###### The Style Code

Python Enhancement Proposal (PEP) လို့ခေါ်တဲ့ code ကို ဘယ်လို style ကျကျထားရမလဲဆိုတာ ညွှန်ပြပေးတဲ့ documentation။ one of the oldest one is PEP-8.

Some guidelines:

- Indentation - four spaces per indentation lvl
- Line Length - recommend each line should be less than 80 chars
- Blank line - to group parts of the program visually

read more : https://python.org/dev/peps/pep-0008
