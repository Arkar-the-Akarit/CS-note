
list တစ်ခုထဲက items တွေကို အကုန်ထုတ်ကြည့်ချင်တယ်ဆိုရင် <mark style="background: #FFF3A3A6;">for loop</mark> ကို သုံးလို့ရတယ်။

```
fruits = ['strawberry', 'banana', 'cherry
]

for fruit in fruits:
	print(fruits)

```

###### Closer look at Looping

`for fruit in fruits:`
ဒီ statement က python ကို fruits list ထဲကနေပြီး ပထမဆုံး value/item ကိုထုတ်ပြီး fruit ထဲကို assign လုပ်တယ်။

`print(fruit)`
fruit ထဲမှာရှိနေတဲ့ value ကိုပြန်ထုတ်ပေးတယ်။ ပြီးရင် fruits list ထဲမှာ item ကုန်/မကုန်ကြည့်တယ်။ မကုန်သေးရင် ပထမအဆင့်ကို ပြန်သွားတယ်။ ခုနက assign လုပ်လိုက်တဲ့ lists item/value အနောက်က တစ်ခုကို fruit ထဲ ပြန် assign လုပ်ပေးတယ်။ အဲ့လိုနဲ့ item မကုန်မခချင်းရေးတော့တာဘဲ

နောက်ဆုံး value ကို ထုတ်ပြီးသွားရင် loop က ရပ်သွားမှာဖြစ်ပေမယ့် temp valueဖြစ်တဲ့ fruit သည် scope အတွင်း ရှိနေသရွေ့ စိတ်ကြိုက်ပြန်သုံးလို့ရတယ်။

```
def my_funciton():
	for fruit in fruits:
		....

	print(fruit)

```
