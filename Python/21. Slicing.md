
slicing လုပ်တယ်ဆိုတာက အလွှာလိုက်/အပိုင်းလိုက် ဆွဲထုတ်ပြီး data တွေကို ကိုင်တွယ်တာ။ indexing လို data တစ်ခုဆီကို manage လုပ်တာမဟုတ်ဘဲ အများကို လုပ်တာဖြစ်တယ်။

###### 1. start, stop, step

index နံပါတ်တွေနဲ့ အလုပ်လုပ်တယ်။

start - စမှတ်
stop - ဆုံးမှတ် (exclusive, သူ့ကိုထည့်မထုတ်ဘဲ သူ့ရှေ့က ကောင်မှာ ဆုံးမယ်)
step - ဘယ်လိုသွားမလဲ။ တစ်တိုးမလား၊ နှစ်တိုးမလား၊ နောက်ပြန်ပြန်ထုတ်ချင်တာလား။ အဲ့လို

left - right -> +   , right - left -> -

စမှတ်, ဆုံးမှတ်တွေကို <mark style="background: #BBFABBA6;">full colon (:)</mark> ထည့်ပြီးသုံးရတယ်။

<span style="color:rgb(0, 176, 240)">start point</span> ကို <span style="color:rgb(0, 176, 240)">blank ချန်ပြီး</span> အစကနေ ထုတ်ချင်တဲ့ထိဘဲ ထုတ်လညး်ရ
<span style="color:rgb(0, 176, 240)">stop point</span> ကို <span style="color:rgb(0, 176, 240)">blank ချန်ပြီး</span> စမှတ်ကနေ အဆုံးထိ ထုတ်လည်းရ `x[3:]`
start, end မပါဘဲ slicing လုပ်ရင် အကုန်ထုတ် `x[:]`

step ပါမယ် ။ stop point အနောက်မှာ <mark style="background: #BBFABBA6;">colon :</mark> နဲ့ဆက်လိုက်တာဘဲ။
<mark style="background: #ABF7F7A6;">x[start:end:step]</mark>

```
x = "abcde"

x[1:4]   # bcd
x[-4:-1]  # bcd     / x[-2:-5]  # dcb

x[:4]     # abcd
x[1:]     # bcde

x[0:4:1]  # abcd , တစ်ဆင့်ချင်းဆီထုတ်တယ်
x[0:4:2]  # a d , နှစ်ဆင့်ဆီထုတ်တာ

x[4:1:-1]  # edc   end point မပါလည်းရ နောက်ဆုတ်ထုတ်တာဆုိတော့
(or)
p = x[-3:]
p[::1]  # edc

x[0::2]   # a c e



  
```

```
x="abcdefg"

first five -> x[:5]

last five -> x[-5:]

reverse -> x[::-1]

first five reverse -> x[:5], y[::-1]

last five rverse -> x[-5:], y[::-1]


အလယ်ကအမှတ်ကိုရှာချင်ရင် indexing လိုဘဲ odd ဆို စုစုပေါင်းကို 2 စား, even ဆို 2 နဲ့စား (for left mid) +1 (for right mid)။ mid point ရမှ end point, start point ကို လိုသလိုရှာလို့ရ

အလယ်သုံးခုဆို (mid - 1) start point, (mid + 2) end point
အလယ်ငါးခုဆုိ (mid - 4) start point, (mid + 5) end point


# for odd
where n = the quantity of numbers wanted to produce

start = m - (n//2)
stop  = m + ( (n//2) + 1)


# for even

start = m - (n//2)
stop = m + (n//2)

```
