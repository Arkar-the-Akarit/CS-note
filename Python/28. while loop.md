
အကြိမ်အရေအတွက် အတိအကျမသိနိုင်တဲ့ကောင်တွေအတွက် သုံးတယ်။

for - iterations အကြိမ်အရေအတွက် အတိအကျသိ
while - အတိအကျမသိ

if - တစ်ကြိမ်ထဲ     (if true:)
while - unlimited (while true:)

###### 1. waiting user input

```
p = input("Pls enter password: ")

while p!= "123456":
	p = input("Pls enter password")
else :
	print("login successfully")
```

```
p = ""

for _ in range(5):
	p = input("enter password")
	if p == "123456"
		print("Access Granted")
		break  # also break else, the whole for loop
else: 
	print("Wrong 5 times,Try again after 24 hours")

```

while နဲ့ကျ false ဖြစ်လားစစ်ပြီးမှ else - true 
for နဲ့ကျ true ဖြစ်လားစစ်ပြိးမှ else - flase


###### Pythonic naming convention

for loop (iteration) --> i or "proper name"
for loop (repetition) --> "\_" (underscore)

while loop (control)  -> condition check
while loop (repetition) -> True + break
