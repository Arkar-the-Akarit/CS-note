###### checking prime number

prime number ဟုတ်မဟုတ် သိချင်ရင် သိချင်တဲ့ ကိန်းကို သူ့အောက်က နံပါတ်တွေနဲ့ စားကြည့်။ စားလို့ မပြတ်ရင် prime number, ပြတ်ရင် prime number မဟုတ် 

```
num = int(input("please enter a number to check for prime number (not 0 or 1): ))


for i in range(2,num):
	if num % i == 0:
		print(f"Number : {num} is not a prime number")
else:
	print(f"Number : {num} is a prime number")


```

###### finding prime numbers between 1 and 1000

၁ ကနေ ၁၀၀၀ အတွင်း prime number တွေကို ရှာဖို့အတွက်ဆိုရင် ကိန်းတစ်ခုကို သူ့အောက်က ကောင်တွေနဲ့ စားလို့ပြတ်, မပြတ်စစ်ရမယ်။ ဒီတော့ ပထမဆုံး range နဲ့ iteater လုပ်ပြီး num တစ်ခုထုတ်မယ်။ အဲ့ iteration ထဲမှာ nest လုပ်ပြီး first loop ရဲ့ numကို nested loop ထဲမှာ ပြန်သုံးပြီး prime number ကိုရှာ။ အကယ်လို့ စားလို့ပြတ်သွားလို့ prime num မဟုတ်မှန်းသိတာနဲ့ break လုပ်ပြီး ထွက်။

```
p = []

for i in range (1001):
	for j in range (2,i)
		if i % j == 0:
			print(f"num {i} is not a prime number")
		    break
	else :
		print(f"num {i} is a prime number")
		p.append(i)

print(p)


```
