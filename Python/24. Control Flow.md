
Control flow အခြေခံအားဖြင့် (၇)ခု။ program တစ်ခုရဲ့ စီးဆင်းမှုကို ထိန်းချုပ်ဖို့သုံးတယ်

1. Statements
	normal statement, conditional statement တွေဆိုပြီး ကွန်ပြူတာကို တစ်ခုခုလုပ်ဖို့ခိုင်းတာမျိုး

2. if, else, if

3. typecasting
	explicit/direct typecasting   - typecast by programmers
	implicit/indirect typecasting - typecast by python itself 

4. boolean value from - boolean တန်ဖိုးတွေက ဒီကနေထွက်လာတတ်တယ်
	a. auto typecasting
	b. function / method
		`def function_name(parameter): return ...`
	c. operator
		- comparison operator (=\=, !\=, <, >, <=, >=)
		- identity operator (is, is not)
		- membership operator (in, not in)


5. finding code block 
	သက်ဆိုင်ရာ statement တွေရဲ့ သူတို့နဲ့ သက်ဆိုင်တဲ့ code block တွေ (scope)
	- finding code block (4 spaces)
	- checking condition
	- adding new conditional code


```
example programs

def is_even(n):  
    return n % 2 == 0  
  
def is_odd(n):  
    return n % 2 != 0  
  
n = int(input("Enter a number: "))  
  
if n == 0:  
    print(f"{n} is zero.") 
	
elif is_even(n):  
    print(f"{n} is an even number.")  
	
elif is_odd(n):  
    print(f"{n} is an odd number.")  
	
else:  
    print("Wrong input")


```
