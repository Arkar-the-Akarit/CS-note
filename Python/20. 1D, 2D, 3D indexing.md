
###### Indexing & 1D,2D,3D

- access -> \[]
- updated -> =
- delete -> del    `del list[1]` (del လုပ်လိုက်ရင် index ချိန်းသွားမှာကို သတိပြုပါ။)

```
 Example

s1 = ["mg mg", 15, 'A']
s2 = ["ma ma", 15, 'A']
s3 = ["hla hla", 15, 'A']
s4 = ["mg ba", 15, 'A']

s1_name = s1[0] # "mg mg"

s1_age = s1[1]  #15
s1[1] = 20      # s1_age is still 15, pass by value




g_12_students = [s1,s2,s3,s4]

s1_name = g_12_students[0][0] # s1 name "mg mg"

# not exactly the same, but 3d
s5 = ["aa", 15, 'A', [21,35,56]]

3d_list = [s1,s2,s3,s4,s5]

3d_list[4][3]  = [21,35,56]
3d_list[4][3][0]  # 21


```


###### 1D 

- one dimensional data
- single series of data
- single list

```
e.g. 

names = ["Mg Mg", "Ma Ma", "Hla Hla"]
ages = [15,20,30]
s1 = ["Mg Mg", 15, 'A']

```


###### 2D

- two-dimensional data
- Row & Column, collection of 1D
- list of list (nested list)
- table, spreadsheet, image

###### 3D

- three-dimensional data
- row & column & depth, collection of 2D
- list of list of list 
- video (sequence of images over time) (width & height & time)

###### nD

1D --> list
2D --> collection of 1D list
3D --> collection of 2D list
4D --> collection of 4D list
nD --> collection of (n-1)D list
