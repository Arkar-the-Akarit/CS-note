###### list

\[] သီးသန့် တန်ဖိုးမပါရင် empty list

ထည့်ချင်တဲ့ data value ကို \[] ကွင်းထဲမှာ coma ခြားပြီး တစ်ဆက်တည်းထည့်ပေးတာနဲ့ list ရတယ်။

ဖန်တီးထားတဲ့ မူလရည်ရွယ်ချက်ကတော့ homogeneous -တူညီတဲ့ elements အမျိုးအစား တွေထည့်ဖို့ပါ။
```
["apples", "oranges", "banana"] -- fruits
[1,2,3] -- numbers
```

###### tuple

() - empty tuple

() ထဲမှာ ထည့်ချင်တဲ့ type အမျိုးအစား, values တွေထည့်လို့ရ။
heterogeneous - မတူတဲ့ data တွေထည့်ဖို့ ဖန်တီးခဲ့တာဖြစ်တယ်။

တစ်ခါဖန်တီးပြီးသွားရင် အဲ့ထဲကို <mark style="background: #ABF7F7A6;">ထပ်ထည့်တာ, ဖျက်တာမျိုး</mark>တွေတော့ <mark style="background: #FF5582A6;">လုပ်လို့မရတော့ဘူး</mark> 

သတိပြုရန် - tuple ဖန်တီးရင် () ကိုသုံးတာဖြစ်တဲ့အတွက် <mark style="background: #FFF3A3A6;">coma ပါရ</mark>မယ်။ မပါရင် program က သင်္ချာတွက်ဖို့ထည့်လိုက်တာလို့ထင်မယ်။
![[coma is importatn in tuple.png]]
အပေါ်က ကောင်သည် tuple
အောက်က ကောင်သည် int

<mark style="background: #ABF7F7A6;">--></mark>  nested သုံးလို့ရတယ်။
e.g. \[(15.253,25.3523),(15.531,23.422)] ဆိုပြီးရေးထားသလိုဘဲ။ တည်နေရာဆိုတဲ့ တန်ဖိုးသဘောတရားတူတဲ့အတွက် list ကိုသုံးပြီး အထဲက lat, long တွေက မတူညီတဲ့အတွက် tuple နဲ့ nested လုပ်လိုက်တယ်။
ဒီလိုဆိုရင် tuple နဲ့ဖန်တီးထားတဲ့ latitude, longitude တွေကတော့ ပြင်လို့မရပေမယ့် အတွဲလိုက်အနေနဲ့ list ထဲမှာရှိနေတာကိုတော့ ပြင်လို့ရတယ်။

###### dict 

{ } - empty dictionary, not set
{ } ထဲမှာ ထည့်ချင်တာတွေထည့်ရေးလို့ရတယ်။ key : value တွဲပြီးထည့်ရတာဖြစ်တယ်။ 

```
{'name' : 'Mg Mg', 'age' : 20, 'height' : 5.5}

# convention

{
	'name' : 'Mg Mg',
	'age' : 20,
	'height' : 5.5
}


# nested 

{'home' : (15.353, 32.332), 'school' : (3.531, 1.422)}

```

##### set

{} ဒီတိုင်းကြီးရေးထားရင် dictionary လို့ python က ယူဆမယ်။ not set
သင်္ကေတကိုသုံးပြီး empty set ဖန်တီးလို့မရ

colon(:) မပါတဲ့ value အနည်းဆုံးတစ်ခုပါဝင်ပြီး set ကိုဖန်တီးလို့ရ

set ကို ဘယ်မှာသုံးလဲဆိုရင်
```
{'Mg Mg', 'Hla Hla', 'Ma Ma'} -- essay ပြိုင်ပွဲဝင်
{'Ba Ba', 'Mg Mg', 'Aung Aung'} -- chess ပြိုင်ပွဲဝင်
```

အပေါ်မှာဆိုရင် Mg Mg တစ်ယောက်ထဲက ပြိုင်ပွဲနှစ်ခုလုံးပြိုင်ထားတယ်။ ဒီတော့ ပြိုင်ပွဲတစ်ခုဆီမှာ ကစားသမား သုံးယောက်ဆီရှိပေမယ့် တကယ့်ကစားသမား အရေအတွက်က ငါးယောက်ဘဲရှိတယ်။

အဲ့လို total number of player - union, common player - interception စတာတွေအတွက်က set ကိုသုံးတယ်။
