5. Memory address can be overridden.

 x = 1 ဆိုပါတော့ ram ထဲမှာ '၁' တန်ဖိုးရှိတဲ့ int obj တစ်ခုတည်ဆောက်ပြီး လိပ်စာကို label x ထဲမှာ သိမ်းတာဖြစ်တယ်။

အကယ်လို့ x = 2 လို့ရေးလိုက်မယ်ဆိုရင် '၂' တန်ဖုိးရှိတဲ့ int obj အသစ်တစ်ခုကို ram မှာေဆာက်ပြီး label x မှာက အဲ့ '2'တန်ဖိုးရှိနေတဲ့ int obj memory address ကို သိမ်းလိုက်တယ်။ 
ပထမ '၁' int obj ရဲ့လိပ်စာသည် override လုပ်ခံလိုက်ရ။

6. dynamic type

data တွေပြောင်းလဲနိုင်တာကို dynamic type လို့ခေါ်တယ်။ 
အပေါ်မှာဆိုရင် x သည် '1' int obj လိပ်စာထည့်တယ်။ ပြီးတော့ '2' int obj လိပ်စာအဖြစ်ပြောင်းတယ်။ အဲ့လိုပြောင်းလဲတာမျိုးဖြစ်တယ်။

x = 1 ဆိုရင် int obj လိပ်စာထားတယ်။
x = 'string' ဆိုရင် string data type အမျိုးအစား object ရဲ့လိပ်စာအသစ်ဖြစ်ပြီး x သည် စစချင်း int type ကနေ string type ကိုညွှန်တာဖြစ်သွားတယ်။ အဲ့လိုပုံစံကို dynamic type လို့ခေါ်။

ဒီလို label ကို ထည့်ချင်တဲ့ type မျိုးညွှန်းခိုင်းလို့ရတဲ့ language မျိုးကို <mark style="background: #FFF3A3A6;">dynamic type</mark> လို့ခေါ်တယ်။

7. Static Type

C တို့ Java တို့မှာဆိုရင် <mark style="background: #FFF3A3A6;">datatype</mark> ကို <mark style="background: #FFF3A3A6;">အသေသတ်မှတ်</mark>ပေးရတယ်။

`int x; int x =1` စသည်ဖြင့် type သတ်မှတ်ပြီးရေးရတယ်။

အဲ့လိုမျိုးတွေကို <mark style="background: #BBFABBA6;">static type</mark> programming language လို့ခေါ်တယ်။

8. Variable

သူက label, identifier, pointer တွေလို အလုပ်လုပ်တာ<mark style="background: #FFF3A3A6;">မဟုတ်ဘဲ</mark> ခွက်တစ်ခုပုံစံ အလုပ်လုပ်တယ်။

```
int x;
x = 1;
x = 2;
```

int x ဆိုရင် int တွေထည့်လို့ရမယ့် ခွက်တစ်ခုဖန်တီးလိုက်တယ်။
အဲ့လို int x လို့ရေးလိုက်တာနဲ့ လိပ်စာ တစ်ခုရတယ်။
အဲ့လိပ်စာထဲမှာ x = 1 ဆို 1 တန်ဖိုးထည့်လိုက်တယ်။
2 ဆို ၁ တန်ဖုိးကို ဖျက် 2 တန်ဖိုးကို အဲ့လိပ်စာမှာဘဲ ထပ်ထည့်တယ်။
သူသည် ဖန်တီးလိုက်တဲ့ int x လိပ်စာသည် အသေ။ အထဲထည့်တဲ့valueတွေကို ပြင်လို့၇တယ်။ ပြောရရင် ဖန်တီးလိုက်တဲ့ variable ထဲမှာ value ကို direct ထည့်ထားတာဖြစ်တယ်။

static type --> သူသည် variable သုံးပြီး variable တစ်ခုဖန်တီးတယ်။ အဲ့ variable မှာ လိပ်စာရှိသွားပြီ။ value assign လုပ်လို့ရတယ်။ ဒါပေမယ့် လိပ်စာသည် အသေဘဲ။ လိပ်စာမှာရှိနေတဲ့ value သာပြောင်းသွားတာဖြစ်တယ်။

dynamic type --> သူသည် label, pointer စတာတွေနဲ့ ram ထဲက object တည်ရှိရာ လိပ်စာကို ညွှန်းတာဖြစ်တယ်။ label ရှိနေတဲ့ နေရာထဲမှာ value တစ်ခုရှိနေတာမဟုတ်ဘဲ value တည်ရှိနေရာ ram ထဲက memory address ရှိနေတာဖြစ်တယ်။

11. Naming Rules

identifier စတာတွေကို ဖန်တီးရင် နာမည်ပေးတဲ့အခါ လိုက်နာရမယ့် စည်းမျဥ်းတွေရှိ

Mandatory - five rules + (optional) one rules
(one, alpha, number, o, r)

1. Identifier နာမည်တစ်ခုမှာ character တစ်ခု ပါရမယ်။
2. ထိပ်ဆုံးက အစစာလုံးသည် alphabet (or) underscore ဖြစ်ရမယ်။
3. တစ်လုံးထက်ပိုတဲ့ identifierနာမည်ပေးမယ်ဆိုရင် အနောက်စာလုံးတွေသည် alphabets, numbers, (or) underscore ဖြစ်လို့ရတယ်။
4. ကျန်တဲ့ character (e.g. $, +, -) စတာတွေ ပါလို့ မရ
5. reserved keywords တွေကို identifier အဖြစ်သုံးလို့မရ
