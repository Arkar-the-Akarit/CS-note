
<mark style="background: #D2B3FFA6;">bitwise not ဖြစ်တဲ့ ~</mark> ကတော့ <mark style="background: #BBFABBA6;">precedence အဆင့် (၂)</mark> မှာရှိတယ်။ ကျန်တဲ့ကောင်တွေက arithmetic operator အနောက်က လာတယ်။ 

###### Bitwise Operators (Operate on Bits), (<mark style="background: #ABF7F7A6;">shift, and, or2, not</mark>)

bit - bit တစ်ခုစီတိုင်းကို ခလုတ်တစ်ခုလို့ မြင်ကြည့်လို့ရတယ်။ bit တစ်ခုဆီတိုင်းအဖွင့် (1) နဲ့ အပိတ် (0) အခြေအနေ တစ်ခုမှာ တည်ရှိနိုင်တယ်။

byte - <mark style="background: #FFF3A3A6;">bit (8) ခု</mark> တစ်စုကို <mark style="background: #ABF7F7A6;">one byte</mark> လို့ခေါ်တယ်။

bitwise operator ဆိုတာက bit တွေအပေါ်မှာ operations လုပ်ဆောင်တဲ့ကောင်တွေကို ခေါ်တာ။ bit lvl data တွေကို တိုက်ရိုက်ကိုင်တွယ်ဖို့လိုတာတွေ၊ low level programming, system programming, performance optimization, cryptography စတဲ့နေရာတွေမှာ bitwise operator ကိုသုံးကြတယ်။

By Precedence Rank lvl :

2. Bitwise NOT     --->  ~

5. Left shift      --->  <<
   Right shift     --->  >>

6. Bitwise AND     --->   &

7. Bitwise XOR     --->  ^

8. Bitwise OR      --->  |


###### left shift  (<<)

သတ်မှတ်ပေးလိုက်တဲ့နံပါတ်အရေအတွက်အတိုင်း bits တွေကို ဘယ်ဘက်ကို ရွေ့ပေးပြီး ညာဘက်မှာ zero တွေဝင်လာတယ်။ 

(အလွယ်မှတ်နည်းက သတ်မှတ်လိုက်တဲ့နံပါတ်အတိုင်း အနောက်က 0တွေထည့်လိုက်တာဘဲ)

0 b 0 0 0 0 0 0 0 1 << 3  ---    0b00001000
            3 2 1 0

left shift bitwise ဟာ နှစ်ထပ်ကိန်းတွေနဲ့ မြှောက်တာနဲ့ တူတူဘဲ။

left shift တွေသည် binary numberတွေကို ဘယ်ဘက်ကို တစ်နေရာရွေ့ရင် သူရဲ့ decimal numberကို နှစ်တစ်ထပ်နဲ့ မြှောက်တာနဲ့တူ။ နှစ်နေရာဆို နှစ်နှစ်ထပ်။ (just for knowledge)

```
4 - 0b00000100 

0b00000100  << 3 -- 0b00100000 (32)

4 * (2 ** 3)
4 * 8
32

```


###### Right Shift (>>)

သူသည် bits နံပါတ်တွေကို ညာဘက်ကိုရွေ့ပြီး ဘယ်ဘက်မှာ zero တွေဖြည့်ပေးတယ်။

(အပေါ်ကကောင်လိုဘဲ ဒါပေမယ့်သူကကျ အရှေ့ဆုံးကစပြီး သတ်မှတ်လိုက်တဲ့ နံပါတ်အလိုက် 0 တွေဖြည့်တာ)

```
0b00000100 (4)  >> 2 
0b000000001  (1)

```

(just for knowledge) သူကကျ နှစ် ထပ်ကိန်းနဲ့ <mark style="background: #ABF7F7A6;">စားတာနဲ့တူ</mark>

```
4 / (2 ** 2)
4 / 4
1
```

###### Bitwise And (&)

bits တွေကို ပေါင်းပြီး <mark style="background: #BBFABBA6;">နေရာတူတဲ့ bits နှစ်ခုလုံး</mark> <mark style="background: #FFF3A3A6;">1</mark> ဖြစ်မှ <mark style="background: #FFF3A3A6;">1</mark> လို့ယူတယ်။ တူရင် တူတဲ့ တန်ဖိုးပြန်လာတာ (0 နှစ်ခု ဆိုလည်း 0, 0 နဲ့ 1 ဆိုလည်း 0)

```
0b0010 & 0b0011

0b0010 (2)
0b0011 (3)
-------
0b0010

```

###### Bitwise XOR  (^)

exclusive OR - two numbers bit ကိုပေါင်းပြီး <mark style="background: #FFB86CA6;">bit တစ်ခုတည်း</mark> <mark style="background: #FFF3A3A6;">1 ဖြစ်မှ</mark> <mark style="background: #FFF3A3A6;">1 ကို ယူ</mark>တယ်။ <mark style="background: #FFF3A3A6;">နှစ်ခုလုံး 1 ဖြစ်</mark>နေရင် <mark style="background: #FFB86CA6;">0</mark>

```
0b00010 ^ 0b00011

0b00010
0b00011
--------
0b00001

```



###### bitwise OR (|)

bits ကိန်းတွဲနှစ်ခုမှာ တစ်ခုက <mark style="background: #BBFABBA6;">bits တစ်ခု</mark>က <mark style="background: #FFF3A3A6;">1 ဖြစ်တာနဲ့</mark> 1

```
0b0010 | 0b0011

0b0010
0b0011
------
0b0011

```


###### Bitwise NOT (~)

သူက bit တစ်ခုဆီကို ဆန့်ကျင့်ဘက်ပြောင်းပေးတယ်။

~ 0b0011
  0b1100

##### Two's Complement 

history : ကွန်ပြူတာက နံပါတ်တွေကို သိမ်းတဲ့အခါမှာ binary ပုံစံနဲ့သိမ်းတယ်။ အဲ့မှာ အပေါင်းကိန်းဆိုရင် ပြဿနာမရှိပေမယ့် အနှုတ်တွေကိုကျ ဘယ်လိုသိမ်းသလဲပေါ့။

```

Sign - magnitude representation သိမ်းနည်း

5  --> 0000 0101 
ဆိုပြီး အပေါင်းကိန်း ၅ ကိုကျ binary နဲ့ပြထားသလိုသိမ်းတယ်။ -

-5 --> 0000 0101 အနှုတ်ငါးကိုကျ ရိုးရိုးbinary နံပါတ်ဘဲ ဒါပေမယ့် highlight ပြထားတဲ့ 0 အစွန်ဆုံးကျတဲ့ zero နေရာ၊ အရေးကြီးဆုံး msb လို့ခေါ်တဲ့ most significant bit လို့ခေါ်တဲ့ bit နေရာကို - sign အတွက် 0 ကနေ 1 အဖြစ်ပြောင်းသိမ်းတယ်။ ဒီတော့ total bit 8လုံးမှာ အနောက် 7လုံးကိုဘဲ ဂဏန်းသိမ်းဖို့သုံးတယ်။

-5 --> 1000 01010

```

###### two's complement of positive

3 -> 00000011 

အပေါင်းကိန်းတွေကို သိမ်းရင် ရိုးရိုး binary အတိုင်းဘဲသိမ်းတယ်။

###### two's complement of negative

အနှုတ်ကိန်းတွေကျ <mark style="background: #ABF7F7A6;">ပုံသေနည်းနဲ့ သိမ်း</mark>တယ်

- bits အားလုံးကို ဆန့်ကျင်ဘက်ပြောင်း
- 1 ပေါင်း (1 1 ချင်းတူနေရင် 0, ရှေ့တစ်တိုး)

```
e.g. 

 5  --> 0000 0101

        1111 1011

```

sign-magnitude က bit ကို အပြည့်မသိမ်းဘဲ msbကို signအတွက်ထားပေမယ့် 
two complement မှာကျ bit ရှစ်ခုအပြည့်နဲ့ အပေါင်းကိန်းရော၊ အနှုတ်ကိန်းရော သိမ်းတယ်။

two complement မှာက bit အရေအတွက် အသေ၊ ရှစ်ခုဆို ရှစ်ခု၊ 16 bit ဆို 16 ခု

###### 8 bits signed integer

အနှုတ်ကိန်းရောပါတဲ့ 8bits တွေကို ဘယ်လိုသိမ်းလဲပေါ့။

00000000   -> 0
00000001   -> 1
01000000   -> 64
01111111   -> 127
10000000   -> -128
10000001   -> -127
11000000   -> -64
11111111   -> -1

storing -127
	01111111 <- 127
	10000000 <- inverted
	10000001 <- plus one

storing -64
	01000000 <- 64
	10111111 <- inverted
	11000000 <- plus one (two one = zero, plus one forward)        

###### Two complement addition (64 + -1)

 01000000    - 64
+11111111    - -1

100111111    <- 8bit ထက်ပိုနေတဲ့ ရှေ့ဆုံးကကောင်ကို ဖယ်
 00111111    <- 63
