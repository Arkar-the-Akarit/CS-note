အတိုးနှုန်းမှာ နှစ်မျိုးရှိတယ်။ normal & compound (တိုးရင်းပေါင်းတိုး)

normal - တစ်သိန်း ကို တစ်နှစ် တစ်သောင်းရရင် သုံးနှစ်ဆို တစ်သိန်းသုံးသောင်း

compound
	 1 year -> 100000 + 10000
	 2 year -> 110000 + 11000
	 3 year -> 121000 + 12100 = 142000

```
compound interest

amount = 1_000_000
rate = 4 / 100     # adjustable

year_1 = amount * rate
print("interest for first year: ", year_1)

amount += year_1   # total amount
print("Total amount: ", amount)

```

နောက်တစ်နှစ်အတွက် compound ဆိုရင်လည်း ထပ်ပြီး အတိုးရှာ ပြန်ပေါင်း။ အဲ့တာကို တစ်ခုဆီရေးနေရမှာ ကြာတဲ့အတွက် iteration လို့ခေါ်တဲ့ အကြိမ်ကြိမ်ပြန်ပတ်တဲ့ program ကိုသုံးမယ်။

###### interest program with iteration

အလုပ်တစ်ခုကို ထပ်ခါထပ်ခါ ပြန်မရေးဘဲ programကိုဘဲ လုပ်စေချင်တဲ့အကြိမ်အရေအတွက်အတိုင်း အလုပ်လုပ်အောင် loop ပတ်တာကို သုံးလို့ရတယ်။

```

amount = float(input("Please enter initial amount: ))
rate = float(input("Please enter interest rate: )) / 100
years = int(input("Please enter time length: ))

for i in range(years):
	amount += (amount * rate)

print(f"For {years} years, the total amount is {amount : .2f}")


```


###### iterable objects

အဲ့လို အကြိမ်ကြိမ်အလုပ်လုပ်ဖို့လုပ် သတ်မှတ်ပေးနိုင်တဲ့ကောင်တွေကို <mark style="background: #ABF7F7A6;">iterable objects (can produce iterator) </mark> လို့ခေါ်တယ်။
<span style="color:rgb(0, 176, 240)">10 iterable objects</span> - range, str, list, tuple, dict, set, frozenste, bytes, bytesarray, memroyviews

iterable object ဆိုတာ for i in range(5) ဆိုတဲ့ statementမှာ range နေရာမှာ 
ဝင်တဲ့ကောင်တွေ အဲ့ကောင်တွေထဲက data တွေကို လိုသလောက် loop ပတ်ပြီး အသုံးပြုလို့ရတယ်။

iterable object <span style="color:rgb(220, 20, 60)">မဟုတ်တဲ့ data type</span> တွေကတော့ - int, float, complex, boolean, None


###### iterator

iterable object တွေက <mark style="background: #BBFABBA6;">iter method</mark> ကိုထုတ်ပေးနိုင်တယ်။ 
iter method ကနေ iterator တွေထွက်လာတယ်

iterator တွေကသာ iterate လုပ်ပေးပြီး data တွေကို ထုတ်ပေးနိုင်တယ်။

- iter method, next method (iter function, next function)

###### iterable vs iterator

x = \[1,2,3]  # iterable object , list
y = x.\_\_iter\_\_()     # iterator

abstract အနေနဲ့ auto လုပ်ပေးပေမယ့် မြင်သာအောင် iter funtionကို manually ခေါ်သုံးထားတယ်။
x သည် list, x.iter ကို y အပေါ်မှာ သုံးလိုက်တဲ့အချိန်မှာ y သည် list x ထဲ elements တွေကို တစ်ကြိမ်မှ တစ်ခုဆီ ထုတ်ပေးနိုင်မယ့် iterator တစ်ခုဖြစ်လာတယ်။ 

<mark style="background: #BBFABBA6;">--></mark> (1,2,3) ဆိုရင် တစ်ခါထုတ်လိုက်တာနဲ့ iterator ထဲကနေ ထုတ်လိုက်တဲ့ elementသည်မရှိတော့။ တန်ဖိုးတစ်ခုပေးပါဆိုပြီး  next(y) ဆိုပြီး 1 ကို ထုတ်လိုက်ရင် iterator ထဲမှာက (2,3) ဘဲကျန်မယ်။ နောက်တစ်ခါ next(y)ဆိုရင် 2 ထုတ်ပေး, 3 ကျန်
   

iteration တစ်ခုလုပ်လိုက်ပြီဆိုရင် အကြမ်းဖျင်းအားဖြင့် iterable object ဟုတ်မဟုတ် စစ်လိုက်တယ်။ iterable ဖြစ်တယ်ဆိုရင် python iterator တစ်ခုထုတ်ပေးတယ်။

အဲ့ iterator ကနေ ရှိသမျှ element တွေထဲက <mark style="background: #FFB86CA6;">တစ်ကြိမ်မှာ တစ်ခုဆီ</mark> ပြန်ထုတ်ပေးတယ်။

iterble & iterator ဟာ iteration ရဲ့ အစိတ်အပိုင်းဖြစ်ပေမယ့် သူ့တုိ့ကိုယ်ပိုင် concept တွေရှိနေသေးတာတွေဖြစ်တယ်။ အသေးစိတ်အတွင်းကျကျလေ့လာလို့ရ

##### 1. Definite loop

အလုပ်လုပ်မယ့် အကြိမ်အရေအတွက်ကို အတိအကျသတ်မှတ်ပေးထားတဲ့အတိုင် းအလုပ်လုပ်တာမျိုးမျိိုးကို definite loop လို့ခေါ်တယ်။ 

- run for specific number of time
- number of iteration is determined before hand
- for

###### for

`for loopVariable in iterableObject`

<mark style="background: #BBFABBA6;">loopVariable</mark> - takes next value from iterator in each iteration, ပေးချင်တဲ့ နာမည်ပေးလို့ရပေမယ့် အဲ့ loop variable ကို loop ထဲမှာ <span style="color:rgb(220, 20, 60)">ပြန်မသုံး</span> ဘူးဆိုရင် convention အနေနဲ့ underscore (\_) ကိုသုံးတယ်။ e.g. `for _ in range(5)`


for loop အလုပ်လုပ်ပုံ
- <mark style="background: #ADCCFFA6;">iterable</mark> အပေါ်မှာ <mark style="background: #FFF3A3A6;">iter method</mark> ခေါ်ပြီး  <mark style="background: #BBFABBA6;">itreator</mark> တစ်ခုရလာတယ်။
- <mark style="background: #BBFABBA6;">iterator</mark> ကနေ <mark style="background: #ABF7F7A6;">next function</mark> ကိုခေါ်ပြီး  <mark style="background: #ADCCFFA6;">iterable obj</mark> ထဲမှာ ရှိတဲ့ data တွေ မကုန်မချင်းထုတ်တယ်။ ကုန်ရင် error raise ပြီး next function ကိုရပ်

- စစ်နေရင်းနဲ့ အခြေအနေတစ်ခုမှာဘဲ ရပ်လိုက်ချင်တယ်ဆို <mark style="background: #BBFABBA6;">break</mark> နဲ့ ထွက်လို့ရ

###### <mark style="background: #BBFABBA6;">for - else</mark>

for နဲ့ else နဲ့လည်းတွဲသုံးလို့ရတယ်။ break statement ကို မတွေ့သရွေ့ for loop ကို run တယ်။ ပြီးရင် else block ကို runတယ်။ အကယ်လို့ break statement မပါရင် for loop ကုိ အပြီးထိ run ပြီးမှ else block ကို run တယ်။
