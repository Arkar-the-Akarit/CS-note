###### 2. Memory

memory က ရေရှည် long term, ရေတို volatile ဆိုပြီး ရှိတယ်။

memory က long term memory အပိုင်းမှာ နှစ်မျိုးရှိတယ်။
1. HDD (hard disk drive) - စက်ထဲမှာ သိမ်းတယ်
2. SDD (solid state drive) - digital နည်းနဲ့သိမ်းတယ်

volatile (ရေတို) memory
1. RAM (Randomly Access Memory) - pc ဖွင့်ထားတဲ့အချိန်မှာဘဲသုံးပြီး စက်ပိတ်တာနဲ့ ဖျက်ပေးတယ်။

apps တွေက သူတို့ကို ဖွင့်, အလုပ်လုပ်တဲ့အချိန်မှာ လိုအပ်တဲ့အရာတွေအတွက် RAM ကို သုံးတယ်။

###### 4. RAM, Memory Address, Label

   memory address - ကျွန်တော်တို့ ဖန်တီးလိုက်တဲ့ data တွေကို သိမ်းထားတဲ့ လိပ်စာ

   label - သူက memory address တွေကို သိမ်းထားတဲ့ လိပ်စာကဒ်လိုမျိုးဘဲ (kinda like variable name)

###### 5. Checking Memory Address (id)

object တစ်ခုရဲ့ address ကို သိချင်ရင် id function ကို သုံးလို့ရတယ်။ သူက memory address ကို <mark style="background: #ADCCFFA6;">decimal value</mark> နဲ့ ထုတ်ပေးတယ်။

###### 6. Decimal to hexadecimal (hex())

address တွေကို hexadecimal value နဲ့ဘဲကိုင်တွယ်တာများတဲ့အတွက် ရလာတဲ့ decimal value ကို hex() function သုံးပြီး ပြောင်း

```
x = "house"
id(x)  # 151235

hex(151235) / hex(id(x)) # 0x1081a53

```

###### 7. Everything is an object

e.g. 'apple' ဆိုရင် string object, 1 ဆိုရင် int object
