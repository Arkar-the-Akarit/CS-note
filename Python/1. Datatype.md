2. methods - Objects တွေနဲ့ ဆိုင်တဲ့ functions တွေ

4. lambda - အမည်မရှိတဲ့ functions တွေဖန်တီးဖို့ lambda ကိုသုံးတယ်။ functional programming အပိုင်းမှာ အသေးစိတ်ပါမယ်။ 



###### Ordered & Unordered

order & unordered ဆိုတာက insertion ကိုမူတည်ပြီး ပြောတာ, items/values တွေကို ကိုယ့်ထည့်ထားတဲ့အတိုင်း ပြန်ထုတ်ပေးသလား ၊ arbitrary (ထုတ်ချင်သလို) ပြန်ထုတ်တာလား ပေါ်မူတည်တယ်။

<mark style="background: #ABF7F7A6;">order</mark> - မှာဆိုရင် ထည့်လိုက်တဲ့ ပုံစံအတိုင်း ပြန်ထွက်လာတယ်။
နောက်ထပ်ပြီး insert လုပ်လိုက်တဲ့ values တွေကလည်း insert order ရဲ့ နောက်ကိုဘဲသွားတယ်။
```
list_a = [5, 8, 1];
print(list_a);  # output 5,8,1 
print(list_a[0]); # output 5


```

<mark style="background: #ABF7F7A6;">unorder</mark> - insertion လုပ်လိုက်တဲ့ အတိုင်း ပြန်ထွက်မလာဘူး။ ဒါ့အပြင် <mark style="background: #FFF3A3A6;">duplicate value ကို ဖယ်ပစ်</mark>တယ်။
```
set_b = {5,8,1};
print(set_b); # output 1,5,8 or any order

set_b.add(2);
print(set_b); # ouptput 1,2,5,8 or maybe any order

----

set_c = {3, 8, 3, 2, 9};
print(set_c); # output 2,3,8,9 or maybe any order, no duplicate values

```
