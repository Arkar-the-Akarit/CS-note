
အသုံးများတဲ့ numbering system 4 ခု - deci, binary, octal, hexadecimal

ကွန်ပြူတာက အဓိက သုံးတဲ့ စနစ်သုံးခု - bin, oct ,hex

datatype လိုဘဲ numbering system တွေကို python မှာ အမည်နဲ့၇ော သင်္ကေတနဲ့ရော ဖန်တီးလို့ရတယ်။


bin - `bin(3)` where 3 is decimal or lead by `0b` (0b11, -0b12)

oct - `oct(3)` or lead by `0o` (0o12, -0o22)

hex - `hex(3)` or lead by `0x` (0x1a3, -0xa3)

python မှာ 0b11, 0o23, 0xa3 တို့ဆိုပြီး ဖန်တီးလိုက်တာနဲ့ bin, hex, oct object တွေတည်ဆောက်ပေးမှာမဟုတ်ဘူး။
ငါတို့က integer ကိန်းပြည့်ကို ဒီလိုရေတွက်နည်းနဲ့ တွက်ထားတယ်ဆိုတာ အသိပေးရုံဘဲ။

အကုန်လုံးက int အုပ်စုထဲပါပြီး type() နဲ့စစ်ရင်လည်း int လုိ့ဘဲပြမယ် python က

```
(-0b11, -0b1, 0b0, 0b1, 0b10) # provided by us, 

(-3, -1, 0, 1, 2) # how python understand, output

```

အမည် function သုံးရင်ကျ bin(3), oct(3), hex(3) ဆုိရင်ကျ
အဲ့ထည့်လိုက်တဲ့ decimal value တန်ဖိုးကို သက်ဆိုင်ရာ numbering system အဖြစ်ပြောင်းပြီး string အနေနနဲ့ ထုတ်ပေးတယ်။

```
bin(3)
>> '0b11' #output

```

###### bin,oct,hex - decimal

binary, oct, hex value တွေကို <span style="color:rgb(146, 208, 80)">အရှေ့က code ပါရင်</span> (e.g. 0b, 0x, 0o) ဆိုရင် int() နဲ့ပြောင်းလိုက်ရင် int တန်းထုတ်ပေးမယ်။ 

<span style="color:rgb(255, 155, 0)">code မပါဘူး</span>ဆိုရင် base ကို ထည့် define လုပ်ပေးရတယ်။ e.g. (int(1011,2)) 

အကယ်လို့များ input ကိုသုံးခဲ့ရင် သူ့ဆီက ပြန်လာမှာသည် string ဖြစ်တဲ့အတွက် code ပါရင်တောင် <span style="color:rgb(0, 176, 240)">base ကိုထည့် define လုပ်</span>ဖို့လိုတယ်။ အလွယ်နည်းကတော့ code ပါတဲ့ string ဆုိရင် base ကို 0 ထားလို့ရတယ်။ ဒါဆိုရင် python က auto detect လုပ်ပေးပြီး ပြောင်းပေးမယ်
